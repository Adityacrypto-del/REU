1️⃣ Neural Collapse in CNNs
Neural Collapse is a phenomenon observed in deep neural networks (especially CNNs) during the final phase of training, when training loss is almost zero.

It was formally studied in the paper:
Prevalence of Neural Collapse during the Terminal Phase of Deep Learning Training

2️⃣ Early Exiting in CNNs
Early Exiting is a technique where a neural network can output predictions before reaching the final layer, if it is confident enough.

It is widely used for:

Faster inference

Edge devices

Energy-efficient AI

One famous example:
BranchyNet: Fast Inference via Early Exiting from Deep Neural Networks

🔎 How Early Exiting Works
Instead of:

Input → Conv → Conv → Conv → FC → Output

We add intermediate classifiers:

Input
→ Conv1 → Exit 1
→ Conv2 → Exit 2
→ Conv3 → Final Exit

If confidence > threshold → stop and output prediction.

Fine-grained

🔍 3️⃣ What Is “Geometric Complexity”?
It refers to:

How separated class clusters are

How tangled decision boundaries are

Low complexity:

⚠ High geometric complexity

The pretrained backbone already has structured features.

✔ Fine-tuning strategy

🧩 7️⃣ Why This Is Important
Previous research assumed:

Neural Collapse is inevitable at terminal training.

This paper shows:

🧠 What is Cover’s Theorem?
Cover’s Theorem (1965) says:

A complex pattern-classification problem cast in a high-dimensional space nonlinearly is more likely to be linearly separable than in a low-dimensional space.

In simple words:

👉 If you map data into a higher-dimensional space, it becomes easier to separate with a simple linear classifier.

What is neurosymbolic Adi

“Neuro-symbolic AI” (sometimes informally shortened to things like neurosymbolic AI or mistyped as “neurosymbolic Adi”) refers to a class of AI systems that combine neural networks with symbolic reasoning.

Let’s build it clearly from scratch.

🧠 1️⃣ What is Neural AI?
Neural AI = Deep learning systems like CNNs, Transformers.

Examples:

Image classifiers

Large Language Models

Speech recognition

They are:

✔ Data-driven
✔ Good at pattern recognition
❌ Weak at explicit logical reasoning
❌ Hard to interpret

🧮 2️⃣ What is Symbolic AI?
Symbolic AI = Logic-based systems.

Examples:

Rule-based systems

Knowledge graphs

First-order logic engines

They are:

✔ Interpretable
✔ Good at reasoning
✔ Use rules like:

If A and B → then C
But:

❌ Require manual rule design
❌ Poor at perception (images, audio)

🔗 3️⃣ What is Neuro-Symbolic AI?
Neuro-symbolic AI combines:

🧠 Neural networks → perception & representation
🧮 Symbolic reasoning → logic & structure

So the system can:

See patterns

Understand rules

Reason over structure

🎯 Simple Example
Suppose task:
“Is there a red square above a blue circle?”

Neural part:

Detect objects from image (CNN)

Output: red square, blue circle, positions

Symbolic part:

Apply rule: above(A, B)?

Return logical answer

So:

Neural = what is in image
Symbolic = relationship reasoning

🏗 Architecture Types
There are 3 common approaches:

1️⃣ Neural → Symbolic Pipeline
Neural network extracts features → symbolic engine reasons.

2️⃣ Symbolic Constraints Inside Neural Training
Rules added as constraints in loss function.

3️⃣ Fully Integrated Models
Neural network encodes logical structure directly.

🧠 Why Neuro-Symbolic AI Matters
Neural networks:

Learn representations

Show neural collapse geometry

Create high-dimensional feature space

Symbolic systems:

Operate in structured, discrete spaces

Enforce constraints

Neuro-symbolic AI tries to bridge:

Continuous geometry (neural)
Discrete logic (symbolic)

🔗 Connection to Neural Collapse
Neural Collapse creates:

Symmetric class geometry

Structured feature space

That structured representation can make it easier to:

Map neural features to symbolic predicates

Create cleaner reasoning modules

If geometry is clean → symbolic reasoning layer works better.

🚪 Connection to Early Exiting
In early exiting:

Early layers capture low-level features

Later layers capture abstract representations

Neuro-symbolic systems often:

Attach symbolic reasoning to deeper layers

Or use structured intermediate outputs

If early layer representation not structured → symbolic reasoning unreliable.

import os

from torch.utils.data import Dataset

class CarsDataset(Dataset):
    def __init__(self, root_dir, transform=None):
        self.root_dir = root_dir
        self.images = os.listdir(root_dir)
        self.transform = transform

    def __len__(self):
        return len(self.images)

    def __getitem__(self, idx):
        img_path = os.path.join(self.root_dir, self.images[idx])
        image = Image.open(img_path).convert("RGB")
        if self.transform:
            image = self.transform(image)
        return image

# ================================
# COMPLETE FOOD-101 DATA ANALYSIS

import os
import cv2
import numpy as np
import matplotlib.pyplot as plt
from tqdm import tqdm
from skimage.feature import graycomatrix, graycoprops

# ------------------------
# SET DATASET PATH
# ------------------------
base_path = "food-101/images"

if not os.path.exists(base_path):
    raise Exception("Dataset not found. Make sure food-101 is extracted correctly.")

classes = os.listdir(base_path)

# To limit runtime (increase later if needed)
MAX_IMAGES = 1000  

# ------------------------
# INITIALIZE STORAGE
# ------------------------
widths, heights = [], []
r_vals, g_vals, b_vals = [], [], []
edge_densities = []
contrasts, homogeneities, energies, correlations = [], [], [], []

count = 0

print("Processing images...")

for cls in classes:
    images = os.listdir(os.path.join(base_path, cls))
    
    for img_name in images:
        img_path = os.path.join(base_path, cls, img_name)
        img = cv2.imread(img_path)
        
        if img is None:
            continue
        
        # ------------------------
        # 1️⃣ Resolution
        # ------------------------
        h, w, _ = img.shape
        heights.append(h)
        widths.append(w)
        
        # ------------------------
        # 2️⃣ Color Histogram
        # ------------------------
        b, g, r = cv2.split(img)
        r_vals.extend(r.flatten())
        g_vals.extend(g.flatten())
        b_vals.extend(b.flatten())
        
        # ------------------------
        # 3️⃣ Edge Density
        # ------------------------
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        edges = cv2.Canny(gray, 100, 200)
        edge_density = np.sum(edges > 0) / edges.size
        edge_densities.append(edge_density)
        
        # ------------------------
        # 4️⃣ Texture (GLCM)
        # ------------------------
        small_gray = cv2.resize(gray, (128,128))
        glcm = graycomatrix(
            small_gray,
            distances=[1],
            angles=[0],
            levels=256,
            symmetric=True,
            normed=True
        )
        
        contrasts.append(graycoprops(glcm, 'contrast')[0,0])
        homogeneities.append(graycoprops(glcm, 'homogeneity')[0,0])
        energies.append(graycoprops(glcm, 'energy')[0,0])
        correlations.append(graycoprops(glcm, 'correlation')[0,0])
        
        count += 1
        if count >= MAX_IMAGES:
            break
    if count >= MAX_IMAGES:
        break

print("Finished processing", count, "images")

# ==========================================
# 📊 PLOTTING RESULTS
# ==========================================

plt.figure(figsize=(18,12))

# Resolution
plt.subplot(3,2,1)
plt.hist(widths, bins=20)
plt.title("Width Distribution")

plt.subplot(3,2,2)
plt.hist(heights, bins=20)
plt.title("Height Distribution")

# RGB Histogram
plt.subplot(3,2,3)
plt.hist(r_vals, bins=50, alpha=0.5, label='Red')
plt.hist(g_vals, bins=50, alpha=0.5, label='Green')
plt.hist(b_vals, bins=50, alpha=0.5, label='Blue')
plt.legend()
plt.title("RGB Color Histogram")

# Edge Density
plt.subplot(3,2,4)
plt.hist(edge_densities, bins=30)
plt.title("Edge Density Distribution")

# Texture - Contrast
plt.subplot(3,2,5)
plt.hist(contrasts, bins=30)
plt.title("Texture Contrast")

# Texture - Homogeneity
plt.subplot(3,2,6)
plt.hist(homogeneities, bins=30)
plt.title("Texture Homogeneity")

plt.tight_layout()
plt.show()

# ==========================================
# 📌 SUMMARY STATISTICS
# ==========================================

print("\n===== SUMMARY STATISTICS =====")
print("Average Width:", np.mean(widths))
print("Average Height:", np.mean(heights))
print("Average Edge Density:", np.mean(edge_densities))
print("Average Contrast:", np.mean(contrasts))
print("Average Homogeneity:", np.mean(homogeneities))
print("Average Energy:", np.mean(energies))
print("Average Correlation:", np.mean(correlations))

# ================================
# SAFE FOOD-101 DATA ANALYSIS
# ================================

import os
import cv2
import numpy as np
import matplotlib.pyplot as plt
from skimage.feature import graycomatrix, graycoprops

base_path = "food-101/images"

classes = os.listdir(base_path)

MAX_IMAGES = 300   # SAFE LIMIT

# Storage
widths, heights = [], []
edge_densities = []
contrasts, homogeneities, energies, correlations = [], [], [], []

# Histogram bins
r_hist = np.zeros(256)
g_hist = np.zeros(256)
b_hist = np.zeros(256)

count = 0

print("Processing images...")

for cls in classes:
    images = os.listdir(os.path.join(base_path, cls))
    
    for img_name in images:
        img_path = os.path.join(base_path, cls, img_name)
        img = cv2.imread(img_path)
        
        if img is None:
            continue
        
        # 1️⃣ Resolution
        h, w, _ = img.shape
        heights.append(h)
        widths.append(w)
        
        # 2️⃣ Histogram (SAFE way)
        for i, col_hist in enumerate([b_hist, g_hist, r_hist]):
            hist = cv2.calcHist([img],[i],None,[256],[0,256])
            col_hist += hist.flatten()
        
        # 3️⃣ Edge Density
        gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
        edges = cv2.Canny(gray, 100, 200)
        edge_density = np.sum(edges > 0) / edges.size
        edge_densities.append(edge_density)
        
        # 4️⃣ Texture
        small_gray = cv2.resize(gray, (64,64))  # smaller for speed
        glcm = graycomatrix(
            small_gray,
            distances=[1],
            angles=[0],
            levels=256,
            symmetric=True,
            normed=True
        )
        
        contrasts.append(graycoprops(glcm, 'contrast')[0,0])
        homogeneities.append(graycoprops(glcm, 'homogeneity')[0,0])
        energies.append(graycoprops(glcm, 'energy')[0,0])
        correlations.append(graycoprops(glcm, 'correlation')[0,0])
        
        count += 1
        if count >= MAX_IMAGES:
            break
    if count >= MAX_IMAGES:
        break

print("Finished processing", count, "images")

import os
import cv2
import numpy as np
import matplotlib.pyplot as plt
from skimage.feature import graycomatrix, graycoprops

base_path = "cars_train/cars_train"

image_files = os.listdir(base_path)

MAX_IMAGES = 300

widths, heights = [], []
edge_densities = []
contrasts, homogeneities = [], []

r_hist = np.zeros(256)
g_hist = np.zeros(256)
b_hist = np.zeros(256)

count = 0

print("Processing images...")

for img_name in image_files:
    
    img_path = os.path.join(base_path, img_name)
    img = cv2.imread(img_path)

    if img is None:
        continue

    # Resolution
    h, w, _ = img.shape
    heights.append(h)
    widths.append(w)

    # RGB Histogram
    for i, col_hist in enumerate([b_hist, g_hist, r_hist]):
        hist = cv2.calcHist([img],[i],None,[256],[0,256])
        col_hist += hist.flatten()

    # Edge Density
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    edges = cv2.Canny(gray,100,200)
    edge_density = np.sum(edges>0)/edges.size
    edge_densities.append(edge_density)

    # Texture
    small_gray = cv2.resize(gray,(64,64))
    glcm = graycomatrix(small_gray, distances=[1], angles=[0],
                        levels=256, symmetric=True, normed=True)

    contrasts.append(graycoprops(glcm,'contrast')[0,0])
    homogeneities.append(graycoprops(glcm,'homogeneity')[0,0])

    count += 1
    if count >= MAX_IMAGES:
        break

print("Processed images:",count)

plt.figure(figsize=(18,10))

plt.subplot(2,3,1)
plt.hist(widths, bins=20)
plt.title("Width Distribution")

plt.subplot(2,3,2)
plt.hist(heights, bins=20)
plt.title("Height Distribution")

plt.subplot(2,3,3)
plt.plot(r_hist,color='red')
plt.plot(g_hist,color='green')
plt.plot(b_hist,color='blue')
plt.title("RGB Histogram")

plt.subplot(2,3,4)
plt.hist(edge_densities,bins=20)
plt.title("Edge Density")

plt.subplot(2,3,5)
plt.hist(contrasts,bins=20)
plt.title("Texture Contrast")

plt.subplot(2,3,6)
plt.hist(homogeneities,bins=20)
plt.title("Texture Homogeneity")

plt.tight_layout()
plt.show()

print("Average width:",np.mean(widths))
print("Average height:",np.mean(heights))
print("Average edge density:",np.mean(edge_densities))

import os
import cv2
import numpy as np
import matplotlib.pyplot as plt
from skimage.feature import graycomatrix, graycoprops

base_path = "jpg"
image_files = os.listdir(base_path)

MAX_IMAGES = 300

widths, heights = [], []
edge_densities = []
contrasts, homogeneities = [], []

r_hist = np.zeros(256)
g_hist = np.zeros(256)
b_hist = np.zeros(256)

count = 0

print("Processing images...")

for img_name in image_files:
    
    img_path = os.path.join(base_path, img_name)
    img = cv2.imread(img_path)

    if img is None:
        continue

    # Resolution
    h, w, _ = img.shape
    heights.append(h)
    widths.append(w)

    # RGB Histogram
    for i, col_hist in enumerate([b_hist, g_hist, r_hist]):
        hist = cv2.calcHist([img],[i],None,[256],[0,256])
        col_hist += hist.flatten()

    # Edge Density
    gray = cv2.cvtColor(img, cv2.COLOR_BGR2GRAY)
    edges = cv2.Canny(gray,100,200)
    edge_density = np.sum(edges>0)/edges.size
    edge_densities.append(edge_density)

    # Texture
    small_gray = cv2.resize(gray,(64,64))
    glcm = graycomatrix(small_gray, distances=[1], angles=[0],
                        levels=256, symmetric=True, normed=True)

    contrasts.append(graycoprops(glcm,'contrast')[0,0])
    homogeneities.append(graycoprops(glcm,'homogeneity')[0,0])

    count += 1
    if count >= MAX_IMAGES:
        break

print("Processed:", count)

plt.figure(figsize=(18,10))

plt.subplot(2,3,1)
plt.hist(widths, bins=20)
plt.title("Width")

plt.subplot(2,3,2)
plt.hist(heights, bins=20)
plt.title("Height")

plt.subplot(2,3,3)
plt.plot(r_hist, color='red')
plt.plot(g_hist, color='green')
plt.plot(b_hist, color='blue')
plt.title("RGB Histogram")

plt.subplot(2,3,4)
plt.hist(edge_densities, bins=20)
plt.title("Edge Density")

plt.subplot(2,3,5)
plt.hist(contrasts, bins=20)
plt.title("Texture Contrast")

plt.subplot(2,3,6)
plt.hist(homogeneities, bins=20)
plt.title("Texture Homogeneity")

plt.tight_layout()
plt.show()

print("Avg width:", np.mean(widths))
print("Avg height:", np.mean(heights))
print("Avg edge density:", np.mean(edge_densities))

import numpy as np
import matplotlib.pyplot as plt
import cv2
from skimage.feature import graycomatrix, graycoprops

MAX_IMAGES = 300

widths, heights = [], []
edge_densities = []
contrasts, homogeneities = [], []

r_hist = np.zeros(256)
g_hist = np.zeros(256)
b_hist = np.zeros(256)

count = 0

print("Processing images...")

for i in range(len(dataset)):
    
    img, _ = dataset[i]
    
    # Convert tensor → numpy
    img = img.permute(1,2,0).numpy()
    img = (img * 255).astype(np.uint8)
    
    # Resolution
    h, w, _ = img.shape
    heights.append(h)
    widths.append(w)
    
    # RGB histogram
    for c, hist_arr in enumerate([b_hist, g_hist, r_hist]):
        hist = cv2.calcHist([img],[c],None,[256],[0,256])
        hist_arr += hist.flatten()
    
    # Edge density
    gray = cv2.cvtColor(img, cv2.COLOR_RGB2GRAY)
    edges = cv2.Canny(gray,100,200)
    edge_density = np.sum(edges > 0) / edges.size
    edge_densities.append(edge_density)
    
    # Texture
    small = cv2.resize(gray,(64,64))
    glcm = graycomatrix(small,[1],[0],256,True,True)
    
    contrasts.append(graycoprops(glcm,'contrast')[0,0])
    homogeneities.append(graycoprops(glcm,'homogeneity')[0,0])
    
    count += 1
    if count >= MAX_IMAGES:
        break

print("Processed:", count)

# ===================== PLOTS =====================

plt.figure(figsize=(18,10))

plt.subplot(2,3,1)
plt.hist(widths, bins=20)
plt.title("Width Distribution")

plt.subplot(2,3,2)
plt.hist(heights, bins=20)
plt.title("Height Distribution")

plt.subplot(2,3,3)
plt.plot(r_hist, color='red')
plt.plot(g_hist, color='green')
plt.plot(b_hist, color='blue')
plt.title("RGB Histogram")

plt.subplot(2,3,4)
plt.hist(edge_densities, bins=20)
plt.title("Edge Density")

plt.subplot(2,3,5)
plt.hist(contrasts, bins=20)
plt.title("Texture Contrast")

plt.subplot(2,3,6)
plt.hist(homogeneities, bins=20)
plt.title("Texture Homogeneity")

plt.tight_layout()
plt.show()

# ===================== SUMMARY =====================

print("\n===== SUMMARY =====")
print("Avg width:", np.mean(widths))
print("Avg height:", np.mean(heights))
print("Avg edge density:", np.mean(edge_densities))
print("Avg contrast:", np.mean(contrasts))

import torch
import torchvision.models as models
import matplotlib.pyplot as plt
from PIL import Image
import torchvision.transforms as transforms

# Load model
model = models.resnet18(pretrained=True)
model.eval()

# Hook storage
features = []

def hook_fn(module, input, output):
    features.append(output)

# Register hooks
for layer in model.children():
    layer.register_forward_hook(hook_fn)

# Load image
transform = transforms.Compose([
    transforms.Resize((224,224)),
    transforms.ToTensor()
])

img = Image.open("your_flower_image.jpg").convert("RGB")
img = transform(img).unsqueeze(0)

# Forward pass
with torch.no_grad():
    model(img)

# Visualize first feature maps
for i, f in enumerate(features[:4]):
    plt.figure(figsize=(10,5))
    plt.title(f"Layer {i}")
    
    # show first 6 channels
    for j in range(6):
        plt.subplot(2,3,j+1)
        plt.imshow(f[0,j].cpu(), cmap='gray')
        plt.axis("off")
    
    plt.show()

# ==============================

import torch
import torchvision
import torchvision.transforms as transforms
import torchvision.models as models
import numpy as np
import matplotlib.pyplot as plt

# ==============================
# 2. LOAD DATASET (NO MANUAL DOWNLOAD)
# ==============================
dataset = torchvision.datasets.Flowers102(
    root="./data",
    split="train",
    download=True,
    transform=transforms.Compose([
        transforms.Resize((224,224)),
        transforms.ToTensor()
    ])
)

# ==============================
# 3. LOAD ONE IMAGE
# ==============================
img, label = dataset[0]

# add batch dimension
img = img.unsqueeze(0)

print("Image shape:", img.shape)

# ==============================
# 4. LOAD MODEL (PRETRAINED)
# ==============================
model = models.resnet18(pretrained=True)
model.eval()

# ==============================
# 5. SELECT LAYERS
# ==============================
target_layers = {
    "conv1": model.conv1,
    "layer1": model.layer1,
    "layer2": model.layer2,
    "layer3": model.layer3,
    "layer4": model.layer4
}

# ==============================
# 6. HOOKS FOR FEATURE EXTRACTION
# ==============================
features = {}

def get_hook(name):
    def hook(module, input, output):
        features[name] = output.detach()
    return hook

for name, layer in target_layers.items():
    layer.register_forward_hook(get_hook(name))

# ==============================
# 7. FORWARD PASS
# ==============================
with torch.no_grad():
    model(img)

# ==============================
# 8. COMPUTE STATISTICS
# ==============================
stats = {}

for name, f in features.items():
    f_np = f.cpu().numpy()
    
    stats[name] = {
        "mean": np.mean(f_np),
        "variance": np.var(f_np),
        "sparsity": np.mean(f_np == 0)
    }

print("\n=== Layer-wise Statistics ===")
for layer, values in stats.items():
    print(layer, values)

# ==============================
# 9. VISUALIZE FEATURE MAPS
# ==============================
def visualize(feature, title):
    feature = feature[0]  # remove batch
    
    plt.figure(figsize=(10,5))
    for i in range(6):
        plt.subplot(2,3,i+1)
        plt.imshow(feature[i].cpu(), cmap='gray')
        plt.axis('off')
    plt.suptitle(title)
    plt.show()

for name, f in features.items():
    visualize(f, name)

# ==============================
# 10. PLOT LAYER-WISE TRENDS
# ==============================
means = [stats[k]["mean"] for k in stats]
vars_ = [stats[k]["variance"] for k in stats]

plt.plot(means, label="Mean Activation")
plt.plot(vars_, label="Variance")
plt.legend()
plt.title("Layer-wise Feature Trends")
plt.show()

# ==============================

import torch
import torchvision
import torchvision.transforms as transforms
import torchvision.models as models
import numpy as np
import matplotlib.pyplot as plt

# ==============================
# 2. LOAD DATASET (AUTOMATIC)
# ==============================
transform = transforms.Compose([
    transforms.Resize((224,224)),
    transforms.ToTensor()
])

dataset = torchvision.datasets.Flowers102(
    root="./data",
    split="train",
    download=True,
    transform=transform
)

# ==============================
# 3. LOAD MODEL (DEFINE MODEL HERE)
# ==============================
model = models.resnet18(pretrained=True)
model.eval()

# ==============================
# 4. DEFINE TARGET LAYERS
# ==============================
target_layers = {
    "conv1": model.conv1,
    "layer1": model.layer1,
    "layer2": model.layer2,
    "layer3": model.layer3,
    "layer4": model.layer4
}

# ==============================
# 5. REGISTER HOOKS
# ==============================
features = {}

def get_hook(name):
    def hook(module, input, output):
        features[name] = output.detach()
    return hook

for name, layer in target_layers.items():
    layer.register_forward_hook(get_hook(name))

# ==============================
# 6. MULTI-IMAGE ANALYSIS
# ==============================
num_images = 20

layer_stats = {
    name: {"mean": [], "var": [], "sparsity": []}
    for name in target_layers.keys()
}

for i in range(num_images):
    
    img, _ = dataset[i]
    img = img.unsqueeze(0)
    
    features.clear()
    
    with torch.no_grad():
        model(img)
    
    for name, f in features.items():
        f_np = f.cpu().numpy()
        
        layer_stats[name]["mean"].append(np.mean(f_np))
        layer_stats[name]["var"].append(np.var(f_np))
        layer_stats[name]["sparsity"].append(np.mean(f_np == 0))

# ==============================
# 7. COMPUTE AVERAGE STATS
# ==============================
avg_stats = {}

for layer in layer_stats:
    avg_stats[layer] = {
        "mean": np.mean(layer_stats[layer]["mean"]),
        "variance": np.mean(layer_stats[layer]["var"]),
        "sparsity": np.mean(layer_stats[layer]["sparsity"])
    }

print("\n=== AVERAGE STATS ACROSS IMAGES ===")
for layer, values in avg_stats.items():
    print(layer, values)

# ==============================
# 8. PLOT FINAL GRAPH

layers = list(avg_stats.keys())
